# 💻 PC-Diagnostic-Center — Консольная система конфигурации и диагностики ПК

---
## 🚀 Начало

Добро пожаловать в **PC-Diagnostic-Center**! Это консольное приложение на чистом Python (без сторонних библиотек), предназначенное для автоматизации учета комплектующих, сборки персональных компьютеров, проведения технической диагностики и генерации JSON-отчетов.
---

## 📥 Загрузка и запуск

Чтобы запустить приложение на своем компьютере, выполните следующие шаги:

1. **Клонируйте репозиторий** или скачайте файлы проекта:
   ```bash
   git clone [https://github.com/evgenijpenne/pc_diagnostic_center.git](https://github.com/evgenijpenne/pc_diagnostic_center.git)

```

2. **Перейдите в директорию проекта**:
```bash
cd pc_diagnostic_center

```


3. **Запустите главное приложение** (требуется Python 3.10+):
```bash
python main.py

```


4. **Запустите набор юнит-тестов** (для проверки работоспособности):
```bash
python -m unittest discover -s tests

```
---

## 🌟 Ключевые возможности

Приложение предоставляет широкий набор встроенных функций и алгоритмов:

* ⚡ **Собственные алгоритмы**: Реализация Быстрой сортировки (**QuickSort**) со сложностью $O(n \log n)$ и усовершенствованного **Бинарного поиска** по префиксу со сложностью $O(\log n)$.
* 🧩 **ООП и Архитектура**: Использование базовых классов (`BaseComponent`) и классов-наследников (`Processor`, `StorageDrive`), полиморфизма для расчета состояния деталей и композиции в сборках `PCBuild`.
* 🛡️ **Защита состояния**: Проверка данных на границах через `@property` (блокировка отрицательных цен) и кастомные исключения (`IncompatibleHardwareError`).
* ⚙️ **Ленивая обработка CSV**: Чтение больших файлов комплектующих без полной загрузки в оперативную память через генераторы (`yield`).
* 🔄 **Очередь диагностики**: Организация обслуживания ПК по принципу FIFO с помощью структуры `collections.deque`.
* 📊 **Сохранение и Экспорт**: Сохранение текущего состояния системы и заказов в формат `JSON`.
